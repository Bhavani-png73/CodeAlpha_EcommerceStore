# CodeAlpha E-Commerce Store

A simple E-Commerce Store developed using Django as part of the CodeAlpha Full Stack Development Internship.

## 🚀 Features

- User Registration
- User Login and Logout
- Product Listing
- Product Search
- Product Categories
- Product Details
- Add Products to Cart
- Increase / Decrease Cart Quantity
- Remove Products from Cart
- Checkout
- Payment Method Selection
- Order Processing
- Order Success Page
- My Orders
- Stock Management
- Django Admin Panel

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git
- GitHub
